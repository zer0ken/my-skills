# H4 책임 배치와 모듈 경계

Value: 각 책임이 그 개념의 모듈에 있고 계층 방향을 지킨다

Picked when: 파일이나 모듈을 더하거나 옮기거나, import 를 바꾼다

Broken if: 〈M〉이 계층을 거스르거나 공개 경로를 우회한다. 또는 잡동사니 모듈, 한 곳에서만 쓰는 분할이 생긴다
