# H8 동시성과 복구 설계

Value: 같은 작업의 동시 실행, 중단, 재시도가 하나의 정의된 상태로 끝나고, 순서는 메커니즘이 강제한다

Picked when: 병렬 실행, 잠금, 큐, 재시도, 여러 단계 쓰기가 생기거나 바뀐다

Broken if: 〈작업〉의 결과 상태를 보장하는 잠금, 유일 키, 멱등 키가 없다. 또는 순서가 타이밍에 기댄다
