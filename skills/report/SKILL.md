# Report

Write for a reader who has not followed the conversation. Follow the requested format and length. Put decisions requiring the reader first. For a general report use the applicable headings in this order:

- 무슨 일을 하고 있나. Identify the issue, the problem and one concrete symptom.
- 고치는 방법. Explain the chosen approach and its reason.
- 방침이 바뀐 점. State what changed since the last report and its effect.
- 지금 효과. Say what each number measures and distinguish passed, failed and unrun verification.
- 지금 돌고 있는 일. Name each active task and what its result is needed for. Give the condition for resuming work.
- 남은 일. Place the work against the overall completion criteria.

Omit empty sections and internal labels the reader cannot interpret. Explain a necessary identifier when it first appears. If the turn must end before completion, state what remains on the first line. Use headings and short prose by default; follow an explicit request for bullets or a different format.
