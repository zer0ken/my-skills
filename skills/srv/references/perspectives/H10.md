# H10 신뢰 경계 지도

Value: 변경이 만든 신뢰할 수 없는 입력의 출처와 위험한 사용처 사이에 검증이 있다

Picked when: 사용자 입력, 파일, 모델 출력, 다른 서비스, 자격 증명, 인증·인가를 다룬다

Broken if: source 〈S〉에서 sink 〈K〉까지 검증 없는 경로가 있다. 또는 인증·인가가 내부 논리 뒤에 있다

Sources: E36 (OWASP source to sink); rv U3 security (`~/.agents/skills/rv/SKILL.md`). REVIEW-TECHNIQUES 4.2.
