# L11 시험 단언

Value: 바뀐 동작의 시험이 변경 전 코드에서 실패하고, 계약이 정확한 곳에서 단언도 정확하며, 대역이 실제 구현과 같은 형태를 돌려준다

Picked when: 시험이 생기거나 바뀐다

Broken if: 시험 〈T〉가 변경 전 코드에서도 통과한다. 또는 접미사, 참거짓 단언으로 정확한 계약을 느슨하게 본다. 또는 대역 〈D〉의 반환 형태가 실제와 다르다
